## Contributing

We welcome contributions! Here's how you can help:

### Getting Started

1. **Fork** this repository and create your branch from `main`.
2. **Open in Codespaces** — click the green **Code** button and select **Open with Codespaces** to get a pre-configured development environment instantly.
3. Make your changes and **test** them locally.
4. **Submit a pull request** with a clear description of what you changed and why.

### Development Setup

This project uses [GitHub Codespaces](https://github.com/features/codespaces) for development. To get started:

```bash
# Clone the repository
git clone https://github.com/ArabianLove/friendly-journey.git

# Navigate into the project
cd friendly-journey

# Run the sample script
python src/hello.py
```

### Code Style

- Follow [PEP 8](https://peps.python.org/pep-0008/) for Python code.
- Keep changes focused and minimal — one concern per pull request.
- Write clear, descriptive commit messages.
- All contributors are expected to abide by the project's [Code of Conduct](https://www.contributor-covenant.org/version/2/1/code_of_conduct/code_of_conduct.md).
